# Data Coverage

A quick way to see which KPIs have data for which countries and years, without opening every dashboard individually.

## When to use this

- **After a KPI upload** — confirm the year/country combination you just uploaded actually shows up, before telling stakeholders the data is live.
- **Before a reporting cycle** — spot gaps (a country missing a KPI for the current year) early enough to chase down the source file.
- **When a dashboard looks empty** — check here first to see if it's a genuine data gap or a display/permissions issue elsewhere.

## Reading the page

The table lists every KPI with a status (**Complete** / **Partial** / **Missing**), how many countries and years have data, the latest year, and when it was last updated. Search, or filter by country, year, status, or KPI group, to narrow it down — and export the filtered list as a CSV.

Click a row to open its detail view: a country × year heatmap (a cell shows the record count, or an **✕** for a gap) plus a list of every missing country/year combination for that KPI. A gap doesn't necessarily mean something is broken — some KPIs are only collected for certain countries or only in certain years.
