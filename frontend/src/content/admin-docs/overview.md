# Admin Overview

The admin section is where SHF Agriculture staff manage data ingest, KPI uploads, users, and reporting configuration for the portal. It's separate from the main reporting dashboards — everything here controls *how data gets in* and *who can see what*, rather than displaying reports themselves.

## Two levels of access

| Role | What they see |
|---|---|
| **Admin** | Full sidebar — Overview, Users, User Roles, Dashlet Comments, KPI Upload, KPI Data Coverage, Salesforce Log, Salesforce Recon, WhatsApp, Portal Usage |
| **Country Admin** | A reduced sidebar — only Users and this Documentation page. Country admins manage user access for their own country but don't touch ingest, KPIs, or global configuration. |

Your role is set by an admin from the **Users** page and can't be changed by you — an admin also can't change their own role, so a second admin is always needed to make that change.

## Where to start

- Setting up a new starter? See the **Users** tab.
- Data looking stale or wrong? See the **Salesforce Ingest** and **Salesforce Recon** tabs.
- Need to load or refresh KPI figures? See the **KPI Upload** tab.
- Deciding who can see which dashboards? See the **User Roles** tab for permissions, and the **Users** tab for which countries' data they see — a user needs both to see anything.
