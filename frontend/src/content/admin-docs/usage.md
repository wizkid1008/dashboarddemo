# Portal Usage

High-level analytics on who's using the portal and which parts of it get the most traffic.

## What to look for

- **Active users over time** — whether adoption is growing, and whether a rollout to a new team or country actually landed.
- **Most-visited pages** — which dashboards and reports get the most use, useful for prioritizing where to invest in new features or fixes.
- **Login activity** — a rough signal for whether invited users have actually started using their accounts, complementing the pending/active status shown on the Users page.

This page is for understanding overall portal adoption, not for auditing an individual user's specific actions.
