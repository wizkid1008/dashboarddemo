# Dashlet Comments

Add or edit the short explanatory note shown under a dashboard card (dashlet), and control whether that note is visible to viewers.

## How it works

- Cards are grouped the same way they appear on the dashboard, by sub-level section.
- Each card has a comment box and a **Show on dashboard** checkbox — leave it unchecked to keep a comment saved but hidden.
- **Edits publish straight to the live dashboard** — there's no draft/preview step here. Save takes effect immediately for everyone with access to that card.
