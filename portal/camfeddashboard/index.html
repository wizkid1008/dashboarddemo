How to Use the Data Dashboard

Explore programme data by selecting a level, sub level, year range, and country using the filters above.

1
Select a Data LevelChoose a programme level from the Level dropdown above.
2
Select a Sub LevelNarrow down to a specific area within your chosen level.
3
Select Year(s)Use the date range slider — move both ends to the same year for a snapshot view.
4
Select a CountryFilter by a specific country or view all countries together.
→For school and district level data, switch to Dynamic Data using the view selector at the top.

    How to Use Dynamic Data

    Drill into country, district, and school-level data for any metric across any year range.

    1
    Select a CountryChoose from the Country dropdown to load district data.
    2
    Narrow to a DistrictOnce a country is selected the District dropdown activates.
    3
    Drill to a SchoolOptionally select a specific school for granular data.
    4
    Set the Year RangeUse the date sliders to view a snapshot or trend.
    →Charts automatically switch between single-year and multi-year views based on your date range.

    How to Use the Slicer

    Build a custom cross-geography analysis — combine any metrics, geographies, gender filter, and chart type.

    1
    Filter GeographyUse Countries, Districts, and Schools dropdowns to narrow scope.
    2
    Pick KPIsSelect up to 8 metrics to compare side by side.
    3
    Filter by GenderChoose All, Female, or Male to segment results.
    4
    Choose a Chart TypeSelect Number, Line, Bar, Pie, Multi-Line, or Table.
    →Set a year range first — the Slicer shows trends for every selected KPI across the years you choose.
